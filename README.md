# pp_calc
# Калькулятор парентерального питания у детей

## Описание проекта

Калькулятор предназначен для расчёта компонентов парентерального питания (ПП) у детей с учётом объёма и нутритивного состава энтерального питания (ЭП).

Приложение позволяет рассчитать суточную потребность в компонентах парентерального питания, определить объёмы необходимых инфузионных растворов и оценить суммарное поступление энергии и основных нутриентов из энтерального и парентерального питания.

Калькулятор реализован на Python с использованием библиотеки Streamlit и имеет веб-интерфейс.

## Основные возможности

- **Расчёт энтерального питания:** выбор молочной смеси из встроенного списка, указание объёмов отдельных кормлений и автоматический расчёт суточного объёма, энергетической ценности и содержания основных нутриентов.
- **Расчёт парентерального питания:** определение объёмов растворов глюкозы, аминокислот, жировой эмульсии, электролитов и витаминных препаратов.
- **Расчёт углеводной нагрузки:** определение необходимого объёма растворов глюкозы заданной концентрации с учётом скорости введения углеводов.
- **Учёт электролитов:** расчёт объёмов растворов калия, натрия, кальция и магния.
- **Оценка суммарного нутритивного обеспечения:** расчёт поступления энергии, белков, жиров и углеводов с учётом энтерального и парентерального питания.
- **Расчёт скорости инфузии:** определение скорости введения растворов глюкозы, аминокислот, электролитов и жировой эмульсии.
- **Экспорт результатов:** формирование и скачивание файла Excel с исходными параметрами и результатами расчёта.

## Входные параметры

Для выполнения расчёта необходимо указать:

### 1. Параметры ребёнка и энтерального питания
- Масса тела, кг.
- Используемая молочная смесь.
- Количество кормлений в сутки.
- Объём каждого кормления, мл.

В программе предусмотрены следующие варианты молочных смесей:
- НАН ГА;
- преНАН 0;
- преНАН 1.

### 2. Параметры парентерального питания
- Общий объём жидкости (ЭП + ПП), мл/кг/сут.
- Доза белка, г/кг/сут.
- Доза жиров, г/кг/сут.
- Скорость введения углеводов, мг/кг/мин.
- Дозы калия, кальция, натрия и магния.
- Дозы витаминных препаратов (Солувит, Виталипид).
- Концентрации используемых растворов глюкозы.

## Результаты расчёта

По заданным параметрам приложение формирует следующие результаты:

- Общий суточный объём жидкости.
- Суточный объём парентерального питания.
- Объём энтерального питания, учитываемый при расчёте инфузии.
- Необходимый объём и расчётную концентрацию раствора глюкозы.
- Объёмы растворов аминокислот и электролитов.
- Объём жировой эмульсии и витаминных препаратов.
- Скорость введения инфузионных растворов, мл/ч.
- Суммарное поступление энергии и основных нутриентов из ЭП и ПП.

Результаты можно скачать в формате `.xlsx` для дальнейшего использования и документирования расчётов.

### Требования

- Python 3.9 или выше.
- Установленные библиотеки:
  - streamlit
  - pandas
  - openpyxl

### Установка зависимостей

Клонируйте репозиторий:

```bash
git clone https://github.com/a-kaplina/pp_calc.git
cd pp_calc
```

Установите необходимые библиотеки:

```bash
pip install streamlit pandas openpyxl
```

### Запуск приложения

Выполните команду:

```bash
streamlit run calc_excel.py
```

После запуска приложение будет доступно в браузере по адресу:

```text
http://localhost:8501
```
